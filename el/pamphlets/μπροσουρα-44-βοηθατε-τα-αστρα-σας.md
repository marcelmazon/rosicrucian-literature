<h1 id="pamphlet-44-are-you-helping-your-stars">Μπροσούρα №44: Βοηθάτε τα άστρα σας;</h1>

### <h3 id="misuse-of-astrology">Κακή χρήση της αστρολογίας</h3>

Δεν είναι σπάνιο να ακούει κανείς σπουδαστές της αστρολογίας να εκφράζουν την ενόχλησή τους για τον τρόπο που λειτουργούν τα άστρα. Παραπονιούνται ότι οι δυσμενείς κατευθύνσεις (directions) είναι πάντα ακριβείς στην ώρα τους και έντονες στην επίδρασή τους, ενώ πολύ συχνά οι ευνοϊκές κατευθύνσεις φαίνεται να έχουν ελάχιστη ή καθόλου επιρροή, και αναρωτιούνται γιατί συμβαίνει αυτό. Έχετε συνειδητοποιήσει ποτέ ότι είναι αδύνατον να πάρετε κάτι χωρίς αντάλλαγμα, όπως ακριβώς δεν μπορείτε να δημιουργήσετε κάτι από το μηδέν; Αυτό ισχύει είτε θέλετε ένα καρβέλι ψωμί, μια θέση εργασίας, χάρες ή οτιδήποτε άλλο. Αν κάποια στιγμή φαίνεται να παίρνετε κάτι χωρίς να πληρώσετε γι' αυτό, θα πρέπει να το εξοφλήσετε αργότερα, και μάλιστα με τόκο, διότι είναι ο Νόμος της Δικαιοσύνης της Φύσης ότι τίποτα δεν δίνεται δωρεάν. Πρέπει να υπάρχει ένα αντίστοιχο αντάλλαγμα με τον έναν ή τον άλλον τρόπο· η πλάστιγγα μπορεί να γέρνει προς μία κατεύθυνση για πολύ καιρό, αλλά όσο σίγουρα το εκκρεμές ταλαντώνεται εξίσου σε κάθε πλευρά του ουδέτερου σημείου, τόσο σίγουρα θα ταλαντευτεί και η πλάστιγγα της δικαιοσύνης, μέχρι να επιτευχθεί η ισορροπία.

### <h3 id="stars-never-compel">Τα άστρα ποτέ δεν αναγκάζουν</h3>

Αυτό ισχύει και στην αστρολογία. Λέγεται ότι «ο Θεός βοηθά εκείνον που βοηθά τον εαυτό του»· μπορείτε επίσης να πείτε ότι τα άστρα βοηθούν τον άνθρωπο που βοηθά τον εαυτό του, διότι αυτά είναι οι λειτουργοί του Θεού. Πρέπει πάντα να θυμόμαστε ότι τα άστρα δείχνουν τάσεις, υποδεικνύουν στιγμές που οι ευκαιρίες είναι ώριμες, αλλά σε καμία περίπτωση δεν αναγκάζουν κανέναν να ενεργήσει με αυτόν ή τον άλλον τρόπο. Όμως, ούτε οι κατευθύνσεις είναι τυχαία γεγονότα. Είναι μαθήματα και εμπειρίες για εμάς, τις οποίες μπορούμε να αξιοποιήσουμε ή όχι, όπως επιλέξουμε, μέσα σε ορισμένα όρια. Για παράδειγμα, η Σελήνη σχηματίζει τετράγωνο με τον Άρη, και αυτό θα μας φέρει μια ευκαιρία να χάσουμε την ψυχραιμία μας και να μπλέξουμε σε μπελάδες εξαιτίας αυτού· στη συνέχεια, όταν ο μπελάς περάσει και καθίσουμε να συλλογιστούμε το συμβάν, πιθανότατα θα πούμε στον εαυτό μας: «μα τι ανόητοι που είμαστε να επιτρέπουμε σε ένα τόσο μικρό πράγμα να καταστρέφει την ευτυχία μας».

### <h3 id="equilibrium">Ισορροπία</h3>

Από την άλλη πλευρά, αν ο σπουδαστής της αστρολογίας χρησιμοποιεί τις γνώσεις του με τον σωστό τρόπο, τότε θα έπρεπε να γνωρίζει ποιο θα είναι το αποτέλεσμα του τετραγώνου Σελήνης-Άρη. Θα έπρεπε να αποφασίσει από πριν να είναι ήρεμος και να πει: «Εδώ είναι μια ευκαιρία για μένα να κυβερνήσω τα άστρα μου. Θα κρατήσω τον θυμό μου υπό απόλυτο έλεγχο, έτσι ώστε ό,τι κι αν συμβεί, να διατηρήσω την ισορροπία μου». Τότε, όταν έρθει η στιγμή να χάσει την ψυχραιμία του, μπορεί να σταθεί ακλόνητος. Αν και μπορεί να νιώθει τα πάθη να αναβράζουν μέσα του, μπορεί να παραμείνει εξωτερικά ήρεμος, να διατηρήσει την ψυχραιμία του και, όταν ο κίνδυνος περάσει, θα έχει κερδίσει μια νίκη και θα έχει μάθει το μάθημα που προοριζόταν να μάθει.

Ή ας υποθέσουμε ότι πρόκειται για ένα τετράγωνο της Σελήνης με τον Κρόνο. Αυτό θα ωθήσει τους ανθρώπους να ανησυχούν και να βλέπουν τη σκοτεινή πλευρά της ζωής, αλλά ο σπουδαστής της αστρολογίας μπορεί να πει στον εαυτό του όταν πλησιάζει ένας τέτοιος σχηματισμός: «Όχι, δεν πρόκειται να ανησυχήσω. Η ανησυχία δεν θα βοηθήσει την κατάσταση. Εμποδίζει, γιατί μου αφαιρεί όλη τη δύναμη με την οποία διαφορετικά θα μπορούσα να ξεπεράσω τις συνθήκες. Θα κοιτάξω τη φωτεινή πλευρά του θέματος και θα δω τι μπορώ να κάνω για να διορθώσω το πρόβλημα».

Στην πραγματικότητα, τα περισσότερα από τα πράγματα για τα οποία ανησυχούμε δεν συμβαίνουν ποτέ, και αν ο σπουδαστής μπορεί να μάθει κάτω από αυτή την πλανητική κατεύθυνση να διατηρεί την ισορροπία του και να σταματήσει να ανησυχεί, τότε έχει κυβερνήσει τα άστρα του και έχει μάθει ένα σημαντικό μάθημα. Έτσι, αν βοηθά τα άστρα του μαθαίνοντας τα μαθήματα που εκείνα προσπαθούν να του διδάξουν, οι δυσμενείς κατευθύνσεις δεν θα έχουν την ίδια δύναμη πάνω του όσο αν απλώς καθόταν με σταυρωμένα τα χέρια, λέγοντας: «Ε, δεν μπορώ να κάνω τίποτα. Είμαι υπό δυσμενείς κατευθύνσεις και φυσικά τα πράγματα είναι καταδικασμένα να πάνε στραβά σε κάθε λεπτομέρεια».

### <h3 id="individual-will">Ατομική θέληση</h3>

Υπάρχει στο ωροσκόπιο ένας κυρίαρχος παράγοντας, συγκεκριμένα: η ατομική θέληση. Έχετε κατά νου ότι το ωροσκόπιο δείχνει μόνο τάσεις και δεν έχει καμία απολύτως δύναμη να σας εξαναγκάσει. Ο εξαναγκασμός προέρχεται από μέσα σας. Εσείς, σε τελική ανάλυση, είστε ο κυρίαρχος παράγοντας σε αυτό το ωροσκόπιο και μπορείτε, ασκώντας επαρκή δύναμη θέλησης, να κυβερνήσετε τα άστρα σας. Είναι παραδεκτό ότι είμαστε όλοι αδύναμοι και επομένως δεν είμαστε σε θέση να ασκούμε την απαραίτητη θέληση ανά πάσα στιγμή, αλλά αυτό ακριβώς είναι που αυτές οι δυσμενείς κατευθύνσεις μάς στέλνονται να καλλιεργήσουμε: μια ισχυρότερη και σταθερότερη θέληση να κάνουμε το σωστό τη σωστή στιγμή. Εξαρτάται από εμάς αν θα εξαναγκαστούμε από τις εξωτερικές περιστάσεις ή από τη δική μας εσωτερική θέληση. Σίγουρα αυτός είναι ο σωστός δρόμος. Οι σπουδαστές της αστρολογίας, πάνω από κάθε άλλον άνθρωπο, θα έπρεπε να είναι σε θέση να οδηγούν τη ζωή τους με ασφάλεια ανάμεσα στους σκοπέλους και τις ξέρες της ύπαρξης, επειδή έχουν την κατάλληλη προειδοποίηση. Γνωρίζουν τι έρχεται και θα πρέπει να προετοιμάζονται γι' αυτό.

### <h3 id="cooperation">Συνεργασία</h3>

Από την άλλη πλευρά, τίθεται το ερώτημα: Γιατί οι ευνοϊκές κατευθύνσεις δεν φέρνουν ένα αντίστοιχο μέτρο οφέλους; Και η απάντηση σε αυτό το ερώτημα είναι: για την ίδια ακριβώς έλλειψη συνεργασίας· είναι εξίσου απαραίτητο να βοηθάμε τα άστρα μας προς μία κατεύθυνση όσο και να τα εμποδίζουμε προς μια άλλη. Είστε χωρίς δουλειά, με τα οικονομικά της οικογένειας ίσως να εξαντλούνται και χωρίς ορατά μέσα αναπλήρωσής τους, αλλά με τις ελπίδες σας επικεντρωμένες σε μια ισχυρή ευνοϊκή κατεύθυνση όπως, ίσως, ένα τρίγωνο της προοδευμένης Σελήνης προς τον κυβερνήτη του έκτου οίκου ή τον Ήλιο; Υπό αυτές τις συνθήκες νιώθετε σίγουροι, από αστρολογική άποψη, ότι πρόκειται να βρείτε μια καλή θέση που θα σας εξασφαλίσει μια άνετη ζωή. Πολύ καλά, μπορείτε να είστε σίγουροι ότι η ευκαιρία θα έρθει, αλλά μην περιμένετε να σας έρθει στο πιάτο χωρίς την παραμικρή προσπάθεια από μέρους σας. Αν κάτι αξίζει να το έχεις, αξίζει να το κυνηγήσεις, αξίζει να καταβάλεις την καλύτερη δυνατή προσπάθεια για να το αποκτήσεις. Μην παραμελείτε καμία λεπτομέρεια: ντυθείτε προσεγμένα αλλά όχι επιδεικτικά όταν πάτε να δείτε το άτομο που έχει τη δύναμη να σας κάνει τη χάρη. Θυμηθείτε, οι πρώτες εντυπώσεις είναι σημαντικές. Έχετε έτοιμα όλα τα «πολεμοφόδιά» σας, όπως συστατικές επιστολές και οτιδήποτε άλλο θα είχατε αν δεν βασιζόσασταν σε μια αστρολογική όψη για να σας βοηθήσει να πάρετε τη θέση. Χρησιμοποιήστε κάθε θεμιτό μέσο για να εντυπωσιάσετε τον υποψήφιο εργοδότη με την ικανότητά σας και να είστε σίγουροι ότι η προσπάθειά σας θα είναι επιτυχής, διότι βοηθήσατε τα άστρα σας· αρπάξατε την ευκαιρία σας.

### <h3 id="common-sense">Κοινή λογική</h3>

Ή μήπως πρόκειται να ξεκινήσετε ένα επιχειρηματικό εγχείρημα με κάποιον άλλον, νιώθοντας πολύ σίγουροι επειδή η Σελήνη σχηματίζει τρίγωνο με τον Ήλιο και την Αφροδίτη στον έβδομο οίκο; Προσέξτε να μην παραμερίσετε την επιφυλακτικότητά σας γι' αυτόν τον λόγο, νομίζοντας ότι υπό μια τέτοια κατεύθυνση κανείς δεν μπορεί να μπει στον συνεταιρισμό σας αν δεν είναι εντάξει. Αν το κάνετε, παραμελείτε το δικό σας μέρος και δεν θα έχετε κανέναν απολύτως λόγο να κατηγορήσετε τα άστρα αν αργότερα αποδειχθεί ότι το άτομο αυτό δεν είναι όλα όσα περιμένατε. Τίποτα δεν χρειάζεται στον κόσμο σήμερα στον ίδιο βαθμό που χρειαζόμαστε την κοινή λογική (ή τη διάκριση), και αυτό ισχύει τόσο για τον τομέα της αστρολογίας όσο και για κάθε άλλον τομέα της ζωής. Η ευκαιρία μπορεί να παρομοιωθεί με μια τσουλήθρα για έλκηθρο ανάμεσα σε εμάς και τις επιθυμίες μας: είναι απαραίτητο για εμάς να καταβάλουμε μια επαρκή αρχική προσπάθεια προκειμένου να σπρώξουμε το έλκηθρό μας σε αυτή την κλίση, αλλά μόλις κάνουμε το δικό μας μέρος, τότε όλα θα κυλήσουν ρολόι υπό ευνοϊκές κατευθύνσεις· τότε τα άστρα είναι μαζί μας για να εντυπωσιάσουν τους άλλους για λογαριασμό μας ή για να ενισχύσουν τη διορατικότητά μας ώστε να γνωρίζουμε τι είναι καλύτερο για εμάς.
