<h1 id="pamphlet-48-help-spread-the-rosicrucian-teachings">Μπροσούρα №48: βοηθήστε στη διάδοση των Ροδοσταυρικών Διδασκαλιών!</h1>

### <h3 id="help-spread-the-rosicrucian-teachings">Βοηθήστε στη διάδοση των Ροδοσταυρικών Διδασκαλιών!</h3>

Η βοήθεια στη διάδοση της Ροδοσταυρικής διδασκαλίας αποτελεί προσωπικό καθήκον του Ροδόσταυρου μαθητή. Οι Πρεσβύτεροι Αδελφοί, οι θεματοφύλακες των Διδασκαλιών της Δυτικής Σοφίας, τις παρέδωσαν στον Δυτικό Κόσμο μέσω του Μαξ Χάιντελ με τον όρο να είναι εξίσου επίμονος στη μετάδοσή τους όσο ήταν και στην αναζήτησή τους. Προφανώς, έχουμε και εμείς μια παρόμοια υποχρέωση να μεταδώσουμε σε άλλους τη γνώση που λάβαμε.

Τι μπορούμε να κάνουμε για να βοηθήσουμε σε αυτό το έργο; Είναι απαραίτητο να έχουμε άμεση γνώση των πνευματικών πεδίων προτού μπορέσουμε να προσφέρουμε υπηρεσία; Όχι! «Υπάρχει ανάγκη ακόμα και για το πιο μικρό κερί». Οι μικροί τροχοί καθιστούν δυνατή τη λειτουργία των μεγάλων.

Η διάδοση των διδασκαλιών μέσω του προσωπικού παραδείγματος είναι το πρώτο πράγμα που πρέπει να εξετάσουμε. Τα μάτια του κόσμου είναι στραμμένα πάνω μας, και το κίνημα της Αδελφότητας (Fellowship) πιστώνεται ή επικρίνεται ανάλογα με τον τρόπο που συμπεριφερόμαστε. Οι γείτονές μας γνωρίζουν κάποια πράγματα για τη ζωή μας, και από τους καρπούς μας αναγνωριζόμαστε.

Το δεύτερο σημείο που πρέπει να εξετάσουμε είναι η διάδοση των Διδασκαλιών μέσω των τοπικών Κέντρων. Τα Κέντρα της Αδελφότητας δεν είναι παρά σύνολα ατόμων, και ένα Κέντρο ως σύνολο θα εκφράζει μόνο ό,τι εκφράζουν τα μέλη του ατομικά. Επομένως, ο καθένας μας έχει μια προσωπική ευθύνη στο να διατηρεί το τοπικό του Κέντρο σε ένα σωστό επίπεδο. Η συνέπεια στην παρουσία και η φροντίδα να συμπεριφερόμαστε με αξιοπρεπή και ευλαβικό τρόπο στις αίθουσες της Αδελφότητας είναι πολύ απαραίτητα στοιχεία. Όταν κατευθύνονται σωστά, τα τοπικά Κέντρα της Αδελφότητας γίνονται μαγνήτες που ελκύουν όσους έχουν ανάγκη από βοήθεια. Όλοι όσοι η τοποθεσία και οι συνθήκες τους το επιτρέπουν θα πρέπει να γίνονται μέλη ενός τοπικού Κέντρου, γιατί «η ισχύς εν τη ενώσει».

Όσον αφορά την προσωπική μετάδοση των Διδασκαλιών, πρέπει πρώτα να εξοικειωθούμε με αυτές επαρκώς, ώστε να μπορούμε να απαντάμε σε ερωτήσεις που αφορούν αυτές. Ο Μαξ Χάιντελ είπε: «Βολιδοσκοπήστε τους ανθρώπους· προσπαθήστε να τους κάνετε να θέσουν ερωτήσεις». Αυτό όμως πρέπει να γίνεται έμμεσα. Δεν πρέπει να επιβάλλουμε τη φιλοσοφία μας στους άλλους. Μπορούμε να ρίχνουμε μια νύξη εδώ κι εκεί, η οποία θα υποδηλώνει ότι κατέχουμε κάποια γνώση πάνω σε αυτά τα ανώτερα ζητήματα. Τότε, αν ο άνθρωπος που μας ακούει είναι έτοιμος για το φως, θα πάρει το μήνυμα και θα θέσει ερωτήσεις. Μετά από αυτό, μπορούμε να προχωρήσουμε όσο φαίνεται ότι μπορεί να αφομοιώσει αυτό που έχουμε να δώσουμε. Όταν οι άνθρωποι ζητούν φως, ωστόσο, δεν πρέπει να το προβάλλουμε πολύ έντονα, γιατί μπορεί να τους τρομάξει και να τους κάνει να απομακρυνθούν.

Κάποιοι μπορεί να αποδεχτούν τη διδασκαλία της αναγέννησης, ενώ άλλοι θα θέλουν να τους εξηγηθούν τα οράματα. Κάποιοι άλλοι θα θέλουν να μάθουν για τις πλανητικές επιδράσεις, την υπόσταση του Χριστού Ιησού ή τον Νόμο της Αιτίας και του Αποτελέσματος. Προσπαθήστε να προσεγγίσετε τους ανθρώπους μέσα από τα δικά τους προβλήματα ζωής. Μιλήστε στους ανθρώπους, όποτε υπάρχει ευκαιρία, για τη βραδινή άσκηση της Αναδρομής, καθώς αυτή είναι ένα πολύ σημαντικό μέσο για την επίτευξη προόδου στην εξέλιξη. Παρεμπιπτόντως, ας μην ξεχνάμε να την εξασκούμε και οι ίδιοι!

Οι άνθρωποι που αντιμετωπίζουν προβλήματα είναι πιο δεκτικοί σε εισηγήσεις που κινούνται στο πλαίσιο των ανώτερων διδασκαλιών. Οι επιτυχημένοι άνθρωποι του κόσμου είναι πιο πιθανό να αντισταθούν σε αυτές τις νέες ιδέες. Η Βίβλος λέει ότι μπορούμε να περιμένουμε να βρούμε οπαδούς ανάμεσα στους ταπεινούς, τις ταλαιπωρημένες ψυχές, τους πεφορτισμένους. Υπάρχουν πολλοί δυσαρεστημένοι, πεινασμένοι και ταραγμένοι άνθρωποι που δεν ξέρουν πού να στραφούν. Προσεύχονται για βοήθεια. Έχουμε ένα προνόμιο και μια ευθύνη όταν ερχόμαστε σε επαφή με τέτοιους ανθρώπους. Δεν πρέπει όμως να ενοχλούμε εκείνους που είναι ικανοποιημένοι ούτε εκείνους που δεν θέλουν να ακούσουν.

Υπάρχει μια άλλη μέθοδος με την οποία μπορούμε να διαδώσουμε τις Διδασκαλίες. Όταν προκύπτει μια κατάσταση που απαιτεί μια δήλωση των Ροδοσταυρικών αρχών, θα πρέπει να παίρνουμε θέση. Θα πρέπει να δηλώνουμε ότι είμαστε χορτοφάγοι· ότι δεν φοράμε για επίδειξη προϊόντα που απαιτούν τη θυσία της ζωής· ότι είμαστε αντίθετοι στον πόλεμο· ότι θεωρούμε τον υπνωτισμό ως πνευματική επίθεση και κακοποίηση και ότι είμαστε αντίθετοι σε όλες τις μορφές αρνητικής πνευματικής ή ψυχικής ανάπτυξης, όπως ο διαμεσολαβητισμός (mediumship). Τέτοιες δηλώσεις δεν πρέπει να γίνονται με προσβλητικό τρόπο, ούτε οι πληροφορίες αυτές να επιβάλλονται στους ανθρώπους. Ας δίνονται φυσικά και διακριτικά.

Ο Μαξ Χάιντελ δήλωσε: «Δεν υπάρχει ψυχική ανάπτυξη όταν κάνουμε μόνο ό,τι έρχεται στον δρόμο μας». Επομένως, πρέπει να είμαστε πάντα σε εγρήγορση για ευκαιρίες να υπηρετήσουμε και να μεταδώσουμε τις διδασκαλίες που μας βοήθησαν. Σχεδόν δεν περνάει μέρα χωρίς να παρουσιαστεί κάποια ευκαιρία να σπείρουμε τον σπόρο της εσωτερικής γνώσης.

Ακολουθεί το θέμα της διάδοσης των εντύπων. Ο καθένας μπορεί να κάνει κάτι. Ενημερώστε τα Κεντρικά Γραφεία ότι θα διανείμετε δωρεάν έντυπα. Δώστε τα σε γείτονες, συγγενείς και φίλους που πιστεύετε ότι θα ενδιαφέρονταν. Τοποθετήστε τα σε πίνακες ανακοινώσεων και συμπεριλάβετέ τα στην αλληλογραφία σας. Δωρίστε μια *Κοσμοθεωρία των Ροδοσταύρων* ή μια συνδρομή στο περιοδικό *Ακτίνες από τον Ροδοσταυρό* (Rays from the Rose Cross) στη βιβλιοθήκη σας, σε ένα νοσοκομείο ή σε έναν φίλο. Χαρίστε ένα αντίτυπο ενός από τα βιβλία, τις διαλέξεις ή τις μπροσούρες μας, που θα μπορούσε να ελκύσει ή να ενδιαφέρει έναν φίλο.

Αν πιστεύετε ότι ένας ή περισσότεροι από τους φίλους σας θα ενδιαφέρονταν για τις συναντήσεις που πραγματοποιούνται στο τοπικό σας Κέντρο, μην παραλείψετε να τους προσκαλέσετε να παρευρεθούν. Στην περίπτωση εκείνων που πιστεύετε ότι είναι έτοιμοι για τις Διδασκαλίες, μιλήστε τους για τα μαθήματα δι' αλληλογραφίας μας, ιδιαίτερα για εκείνα που είναι αφιερωμένα στη Ροδοσταυρική φιλοσοφία. Πολλοί άνθρωποι έρχονται στο κίνημα έχοντας πρώτα προσελκυθεί από την αστρολογία. Η αστρολογία είναι ένα πολύτιμο βοήθημα για τον υποψήφιο στην πρόοδό του στο Μονοπάτι, αλλά έχει σαφώς δευτερεύουσα σημασία σε σύγκριση με τη Φιλοσοφία, και αυτό το σημείο θα πρέπει να τονίζεται στους νεοφερμένους. Δεν είμαστε κυρίως σχολή αστρολογίας, όπως νομίζουν μερικοί.

Διαβάζουμε εβδομαδιαία στην όμορφη προσευχή της Ροδοσταυρικής Αδελφότητας ότι πρέπει να «δίνουμε στους άλλους όλο το θάρρος και την ευθυμία που διαθέτουμε». Οι προηγούμενες προτάσεις μας δείχνουν πώς μπορούμε να το κάνουμε αυτό αποτελεσματικά. Ας μην περιμένουμε από τα Κεντρικά Γραφεία να κάνουν όλη τη δουλειά. Ας ξεκινήσουμε μια ΕΞΟΡΜΗΣΗ. Η Αδελφότητα έχει μαθητές διασκορπισμένους σε όλο τον κόσμο. Αν όλοι κάνουν κάτι, τα Κεντρικά Γραφεία θα δεχθούν μια πρωτοφανή εισροή νέων μαθητών και ερωτημάτων για τα έντυπά μας.

Κάνοντας το χρέος μας πιστά και αφοσιωμένα σε αυτό το σπουδαίο έργο, δεν θα είμαστε μόνο ένας ενεργός παράγοντας βοήθειας προς τους άλλους, αλλά θα κάνουμε επίσης τον μεγάλο Νόμο της Συνέπειας να λειτουργήσει υπέρ μας αντί εναντίον μας, όπως ίσως συνέβαινε στο παρελθόν. Πάνω απ' όλα, ας θυμόμαστε τη βιβλική προσταγή να «μη γνώτω η αριστερά σου τι ποιεί η δεξιά σου». Διότι αν λάβουμε την ανταμοιβή μας και τον έπαινο των ανθρώπων, έχουμε ήδη πάρει την πληρωμή μας, και θα υπάρχουν λίγα προς όφελός μας στα ανώτερα πεδία.
